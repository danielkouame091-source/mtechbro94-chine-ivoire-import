# China–Côte d'Ivoire Import & Export

A Streamlit application for China-to-Côte d'Ivoire import and export information.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Community Cloud

1. Push these files to GitHub.
2. Open Streamlit Community Cloud and choose this repository.
3. Set the main file path to `app.py`.
4. Click **Deploy**.

This project is a Streamlit app. It must be started with `streamlit run app.py`; do not use Flask, Gunicorn, or port 5000 commands.
